Official documentation describes connecting the user's regular browser profile and invoking a desktop browser task; its setup and read-only connection checks are the next prerequisite, not a completed cart proof.

Keep planner inference and desktop execution separate. The report proposes a pinned approved-list revision, a cart baseline and owned-quantity ledger, and a five-ingredient trial that expands to two stores only after a single-store check succeeds. These proposals still need human review and live evidence; no session, prices, availability, or carts were inspected.
