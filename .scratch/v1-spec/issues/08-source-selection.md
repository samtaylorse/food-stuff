## Answer

- The user selected **Good Food** and **RecipeTin Eats** as the initial live-discovery sources on November 12, 2026. Search them as needed rather than maintaining a fixed recipe catalog. This selects technical candidates, not a claim that every access/storage/reuse question has been resolved.
- If a candidate is blocked, incomplete, or otherwise unusable, automatically try another suitable sourced recipe. Interrupt only if no suitable usable recipe can be found. Never invent missing ingredients or instructions.
- Save a local version of each selected recipe's ingredients, faithful concise steps, original yield, title, source reference, and author/publisher where available. Reuse and serving changes use that saved base version rather than silently changing when a website changes.
- Retain cooking information and attribution, without copying article text, comments, or photos. Original attribution, scaled ingredients, and faithful concise steps remain the agreed display.
- Existing support for an identifiable user-supplied source reference in the brief remains; it does not automatically expand the tested website set or excuse incomplete source verification.
- This resolves intended product behavior. Complete extraction correctness and applicable source access/storage/reuse conditions remain evidence gaps to check in [Source-backed recipe extraction trial](10-source-extraction-trial.md). User approval of the product behavior is not a claim of publisher permission or a completed importer.
