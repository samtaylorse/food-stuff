# Meal Planner

A personal meal-planning tool, starting with dinners, designed to make choosing meals and turning them into recipes, shopping lists, and delivery carts easier.

Planned capabilities:

- Flexible weekly batch recipes with clear quantities and cooking steps.
- Pantry, fridge, and freezer photos to help identify what is already on hand.
- Natural-language meal changes that keep recipes and shopping lists consistent.
- Saved favourite recipes for reuse.
- Grocery-store price comparison and cart preparation for review before checkout.

The project is currently in the planning stage; no application has been built yet. See the [project brief](docs/PROJECT_BRIEF.md) for the agreed scope and requirements.
